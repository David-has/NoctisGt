# AURELIUS NOCTIS GT

A premium automotive landing page showcasing the fictional **Aurelius Noctis GT**, an 820 HP hybrid hypercar concept. Designed with a sophisticated dark aesthetic, bronze accents, immersive imagery, and smooth animations.

## Overview

Aurelius Noctis GT is a front-end web development project focused on creating a modern and luxurious digital experience for a high-performance automotive brand.

The website combines elegant typography, cinematic visuals, interactive elements, and responsive design to present the concept car and its specifications.

## Features

- **Luxury Design** – Dark color palette with bronze and gold accents.
- **Responsive Layout** – Optimized for desktop, tablet, and mobile devices.
- **Animated Hero Section** – Large typography, vehicle imagery, and entrance animations.
- **Performance Statistics** – Highlights the vehicle's main specifications.
- **Interactive Specifications** – Tab-based navigation for technical information.
- **Image Gallery** – Interactive gallery with a lightbox preview.
- **Reservation Form** – A dedicated section for potential inquiries.
- **Mobile Navigation** – Responsive navigation menu.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash Images
